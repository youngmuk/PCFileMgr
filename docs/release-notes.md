# PCFileMgr v1.0.0

Windows x64용 디스크 용량 분석 및 조건별 파일 정리 유틸리티의 첫 공개 배포입니다.

## 다운로드와 실행

첨부된 `PCFileMgr.exe`를 다운로드해 실행하세요. 자체 포함 단일 실행 파일로, 별도 .NET 설치가 필요 없습니다. EXE는 디지털 서명되지 않았습니다.

`SHA256SUMS.txt`에서 파일의 SHA-256 값을 확인할 수 있습니다.

## 포함된 기능

- 파일·폴더 크기에 비례하는 용량 지도와 탐색기 형태의 폴더 이동
- 확장자·크기·이름 조건 검색 및 선택 파일의 휴지통 이동
- 삭제 전 경로·개수·용량 검토와 변경된 파일 보호
- Windows 문서 폴더의 공통 분석 캐시와 실행 중 변경분 갱신
- 임시 항목 색상 구분, 다크 테마 스크롤바, 왼쪽 패널 너비 조절
- 전체 화면·검색 결과·검토 창의 실제 스크린샷을 포함한 한국어 사용 안내

## 현재 제한

- 앱 재실행 시 캐시를 먼저 표시한 후 전체 파일 메타데이터를 대조합니다. USN 변경 저널과 DB 지연 로딩은 아직 구현되지 않았습니다.
- 접근할 수 없는 경로, 연결 지점·심볼릭 링크와 일부 클라우드 파일은 집계에서 제외될 수 있습니다.
- 표시 용량은 논리적 파일 크기이며 실제 디스크 점유량과 다를 수 있습니다.
- 정리는 파일 단위이며 휴지통 이동만 지원합니다.

자세한 사용법과 영역별 화면 설명은 저장소의 README를 참고하세요.
